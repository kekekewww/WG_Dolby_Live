WG Studio Live (wg-live) - demo assets
======================================

Files covered:
  demo-tone-1.mp3          demo audio used for the Binaural mode (audio events)
  demo-tone-2.mp3          demo audio used for the Dolby Atmos mode (audio events)
  demo-video-1.mp4         demo video used for the Binaural mode (video events)
  demo-video-2.mp4         demo video used for the Dolby Atmos mode (video events)
  poster-demo.svg          demo poster (16:9)
  poster-demo-square.svg   demo poster (1:1)

Origin
  The two audio files are generated by this project with scripts/generate-demo-audio.mjs
  (ffmpeg, synthesized sine and triangle-like voices). Each is a different, short, gentle piece
  (different key, chord progression, timbre and pacing) so that a mode switch is audible. Format:
  MP3, 96 kbps, 44.1 kHz stereo, about 30 seconds, peak about -18 dBFS, 2 s fades.
  The two video files are generated by this project with scripts/generate-demo-video.mjs (ffmpeg):
  a plain dark field with a yellow accent line, the captions shown below, an elapsed-time counter
  and a progress line, over the matching demo audio file above. Format: H.264 Main, 960x540,
  24 fps, AAC-LC 96 kbps stereo, 30 seconds. The captions are rendered with the Noto Sans TC
  typeface (SIL Open Font License 1.1); the font itself is not included, and text rendered with an
  OFL font is not covered by that license.
  The poster is a hand-written SVG that uses no embedded fonts or images. None of these files
  contains third-party material: no recording, sample, loop, photograph or artwork from any other
  party, and no studio master or performance recording.

License
  Created by the project and shipped with the wg-live plugin. Nothing in these files is
  licensed from a third party, so no third-party notice is required for them.

Purpose
  For interface demonstration only.
  操作示範音訊，非 Binaural／Atmos 驗證素材。
  The video files read 「操作示範影片，非 Binaural／Atmos 驗證素材」.
  They are not Binaural or Dolby Atmos validation material and must not be used to judge
  spatial or immersive playback quality. The two files of each kind are NOT a Binaural render and
  an Atmos render of the same programme; they only differ so that the player can show that a
  different source was loaded. The poster reads 「操作示範，非正式演出」 (a demonstration of the
  interface, not an official performance).
