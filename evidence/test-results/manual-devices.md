# 人工裝置測試紀錄（模板）

對應：規格 §13.2、M1-PLAN §7.4。本檔由人工填寫，開發者與 agent 不得代填、不得以自動化結果替代。

## 填寫規則

1. 每一列是一次真實操作：**實際裝置、實際 OS 版本、實際瀏覽器版本、實際日期**。不以「Safari」「Chrome」這類名稱代替版本。
2. Playwright 的 WebKit **不是** Safari，也不能證明 Apple 硬體或 Atmos 輸出正常。自動化結果放在 `evidence/test-results/` 的其他檔案，不寫進本表。
3. 結果只用下列五種字樣，沒做就留「尚待測試」，不得補成「通過」：

   | 結果 | 意義 |
   |---|---|
   | 通過 | 該項在這台裝置上符合預期 |
   | 部分 | 有差異；在備註寫出實際行為 |
   | 失敗 | 不符合預期；備註附重現步驟，必要時開問題單 |
   | 尚待測試 | 還沒測 |
   | 不適用 | 該裝置沒有這項功能（例如沒有耳機孔），備註說明 |

4. 測試環境欄填 `staging` 或 `production`。正式站只做登出狀態的唯讀操作與示範播放，不下訂單、不登入真實會員帳號進行付款流程（規格 §13.3）。
5. 證據欄放截圖或螢幕錄影的檔名（存在 `evidence/screenshots/`，不進 ZIP），不貼私有網址、帳號或密碼。
6. M1 的示範影音是自製的測試影片（影片活動，預設）與測試音（音訊活動），**不是** Binaural／Atmos 驗證素材。本表任何一列都不能寫成「已驗證 Atmos」。
7. M1 記錄真實行為，不保證所有系統都能背景播放（規格 §13.2）。鎖屏後繼續播或被系統暫停，兩者都如實記錄。

- **鎖屏後行為**：寫「繼續播放」「被系統暫停」或「其他：＿＿」，並確認解鎖後畫面狀態與實際聲音一致。
