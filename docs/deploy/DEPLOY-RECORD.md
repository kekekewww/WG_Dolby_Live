# DEPLOY-RECORD：部署紀錄（模板）

依據：規格 §18.3。**每次更新或回復都留一份**。複製這個檔案，存成 `docs/deploy/records/<日期>-<環境>-<版本>.md`（或團隊指定的位置）後填寫。

**不要寫進紀錄的內容：** 主機帳號與密碼、資料庫密碼、API 金鑰、token、完整私有串流網址、會員個資、管理後台的帶 token 網址。需要指向這些東西時，只寫「存放在 ＿＿（密碼管理工具名稱）」。

沒有做的欄位寫「未執行」並說明原因；不要留空，也不要寫成已完成。

## 7. 回復方式

寫給「半夜接手的人」看得懂的版本。

| 步驟 | 做法 |
|---|---|
| 第一步 | 設定頁部署模式改 `disabled`（[ROLLBACK.md](ROLLBACK.md) 步驟 A） |
| 撤回入口 | 移除首頁區塊與選單項目，**先於**停用外掛（步驟 C） |
| 停用外掛 | 步驟 D |
| 還原上一版 | 上一版 ZIP 位置：＿＿；SHA-256：＿＿ |
| 緊急（後台進不去） | 步驟 5：改名外掛資料夾；執行人：＿＿ |
| 完整資料庫回復 | 預設不做；須管理者確認資料差異。確認人：＿＿ |
