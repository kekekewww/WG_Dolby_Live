## 已實作 (implemented)

- **Demo events are manager-only on production.** On a `production` environment an event with 「示範活動」 is left out of the bootstrap, REST, `/playback`, the homepage card and the shortcode unless the request is a logged-in user with the events capability (`Public_Data::can_see_demo()`). Such answers are `private, no-store`; anonymous answers keep `public, max-age=30`. The player's event poller sends the REST session, so a manager's preview keeps working. Local and staging keep demo events public for testing.
- **No testing text for visitors.** Removed from the site: the help page's 「瀏覽器與驗收說明」 section and 「家庭劇院連接方式」 compatibility table (the table is no longer public data at all: `HelpContent.compatibility` is gone from `src/types.ts` and the PHP payload), the card and help notes about Atmos output and VLC, the label note, the device-output FAQ default, the entitlement note 「觀看資格由伺服器端確認…」, the programme note 「節目單為預定內容…」. Reworded: help intro, guide lead, intermission detail, card chip 「Dolby Atmos」.
- **Admin.** The 「示範活動」 checkbox says it is manager-only on production; the settings' compatibility table is titled 「家庭劇院相容表（內部紀錄）」 and says it is not shown on the site.
- **Kept for visitors:** 播放方式 (Safari, VLC), 沒有聲音時, 重新連線, 用 VLC 收聽, 鍵盤操作, 聯絡我們, admin FAQ; the ticket holders' link panel. Demo labels stay on demo events (only managers see them on production).
