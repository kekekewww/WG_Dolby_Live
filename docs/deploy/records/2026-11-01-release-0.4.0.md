## 已實作 (implemented)

- Server offers only the Dolby Atmos mode; stored Binaural values are dropped; `/playback` for binaural gives no URL. Admin: one 「開放聆聽」 checkbox, only the Atmos HLS / provider-page fields, media type 音訊 (thumbnail) by default; no Binaural demo audio picker.
- Player page: a single-mode event preselects its mode; no 聆聽方式 selector, no 切換模式. Playback still needs 開始聆聽.
- Ticket holders' link panel 「用其他播放器收聽」: an entitled viewer of a live HLS event whose browser cannot decode E-AC-3 (feature detection), or whose playback failed, can fetch a personal link from `/playback` on a click and open it in VLC or Safari.
- Visitor copy (proposed, for approval): the /live/ 聆聽方式 section and the help page describe one Dolby Atmos stream with Safari and VLC cards; the help page has 「用 VLC 收聽」 instead of 切換模式.
