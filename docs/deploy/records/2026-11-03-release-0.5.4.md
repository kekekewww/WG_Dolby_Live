## 已實作 (implemented)

- Event checkbox 「不公開列出」 (meta `_wg_live_unlisted`), saved only when the form carried it (a hidden marker, as for 首頁精選), so a screen opened before 0.5.4 leaves it alone. Below it the event screen shows the link to send to buyers (`/live/listen/?wg_event=<代稱>`). The event list has a 「列出」 column.
- `Public_Data::listed_events()` = the public events minus unlisted ones. Used by REST `events`, the homepage card (`featured_event()`: an unlisted featured event shows the empty card) and every page bootstrap.
- A player page bootstrap adds the unlisted event it is for (the shortcode `event` attribute, else a single valid `?wg_event=`), so its own link opens it. REST `events/<slug>` (the player's poller), `/playback`, the entitlement check and the personal links are unchanged.
- The PublicEvent contract (`src/types.ts`) is unchanged; no client change.
