## 已實作 (implemented)

- A1–A3: ticket ownership from paid WooCommerce orders; `Entitlement::check` in deployment mode 「正式」 (`live`); `/entitlement` and the REST nonce with refresh.
- B1–B3: admin-approved stream hosts; per-event HLS playlists; stream signer selection (production hands out nothing without a signer unless `WG_LIVE_ALLOW_UNSIGNED_STREAMS === true`); `/playback` returns a signed HLS URL only after the ticket check, live/intermission only.
- C1–C4: hls.js as its own file; the HLS adapter (native HLS on Safari 17+/iOS, else the plugin's own hls.js; Atmos refused before any request where E-AC-3 is unsupported); coordinator re-resolves an expired signed URL within the bounded retries; local HLS fixture (`npm run demo:hls`) and e2e.
- D1, D2, D4: provider player (iframe) sources on approved https origins, with a framing warning at save; an iframe adapter with no controls of ours and never 「目前播放」; e2e with a fake provider player.
- Final review fixes: URLs with backslash/userinfo/blanks refused (allowlist bypass); no fake pause on a provider frame.

**Environment:** Playwright WebKit 1.64 on this machine cannot play any mp4 at the moment (a bare page and a bare Node server: `readyState` 0, `play()` never settles). Every WebKit failure is a "the video advances" check. This is not Safari and says nothing about Safari.
